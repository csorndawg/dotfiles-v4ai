# Overview

Newest and latest dotfile repo (as of 2026). This repo aims to do the following:

    - define scope of what will/wont be included in my PERSONAL dotfiles
    - keep dotfiles lean, portable (across all my remote development machines), and significantly improve my CLI experience
    - refactor/consolidate any logic/code from previous dotfile projects (dot_omega & newdots)


# Scope

Any DIG/Windows dotfile configuration code will not be included in this repo. For that code I will create a separate repo, this repo is strictly for my own local development.

Dotfiles Structure/Components
  - zsh shell
  - nvim editor
  - configrc (for CLI utils like FZF, alacritty, ripgrep, etc.)
  - tmux
  - ansible (to install on new machines, assume Ubuntu machines)
